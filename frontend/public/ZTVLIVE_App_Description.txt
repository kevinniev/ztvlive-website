APP DESCRIPTION
---------------
ZTVLIVE is a free 24/7 live streaming TV platform featuring creator-driven 
content including music, podcasts, gaming, and entertainment. The app streams 
continuous live content with no user interaction required after launch.

This is a FREE app with NO in-app purchases and NO subscription required.


MAIN FEATURES
-------------
1. 24/7 Continuous Live Streaming
   - Video playback begins automatically when app launches
   - No user action required to start watching

2. Creator Content
   - Music performances and music videos
   - Podcasts and talk shows
   - Gaming streams
   - Entertainment and variety content

3. Live On-Screen Comments
   - Real-time viewer comments displayed on screen
   - Community engagement features

4. Simple TV-Optimized Interface
   - Designed specifically for TV remote navigation
   - Clean, distraction-free viewing experience


HOW TO TEST THE APP
-------------------
Step 1: Launch the app
        - Video will begin playing automatically within 3-5 seconds
        - No login or setup required

Step 2: Basic Navigation
        - Press UP arrow to access the top menu bar
        - Press DOWN arrow to view on-screen live comments
        - Press LEFT/RIGHT to browse menu options

Step 3: Video Controls
        - Press PLAY/PAUSE button to control playback
        - Press OK/ENTER to select menu items

Step 4: Exit App
        - Press BACK button to return to previous screen
        - Press BACK again from main screen to exit app


REMOTE CONTROL MAPPING
----------------------
Button              Action
------              ------
OK / Enter          Select menu item, confirm action
Back                Return to previous screen / Exit app
Play                Play video
Pause               Pause video
Play/Pause          Toggle play/pause
Up                  Navigate up / Show top menu
Down                Navigate down / Show comments
Left                Navigate left
Right               Navigate right
